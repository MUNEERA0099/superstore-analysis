# **Superstore Statistical and Trends Analysis**

This project presents a statistical and trend‑based analysis of the Superstore dataset using Python in Google Colab. 
It includes data cleaning, exploratory data analysis, and visualisations such as histograms, bar charts, scatter plots, and correlation heatmaps. 
The goal is to understand category‑level sales performance, profit behaviour, and key numerical relationships that influence retail outcomes.
---
## **Contents**
- Notebook with full analysis (`.ipynb`)
- Superstore dataset (`.csv`)
- Visualisations (sales distribution, category comparison, correlation heatmap)
- Summary of insights and trends
---
## **Key Features**
- Statistical analysis of sales and profit  
- Category‑level trend evaluation  
- Correlation analysis of numerical variables  
- Clear visualisations for business interpretation  
---
## **Tools Used**
- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- Google Colab
